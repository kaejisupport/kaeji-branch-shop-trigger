# Kaeji Shop Branch Trigger (Shop Tracker)

ระบบอัตโนมัติสำหรับตรวจสอบและแจ้งเตือนการส่งงานของสาขาหน้าร้าน (เกจิ 99) โดยเชื่อมต่อข้อมูลจาก Google Sheets และส่งแจ้งเตือนผ่าน Telegram Bot

## 🚀 ฟีเจอร์หลัก (Features)
- **Morning Batch (รอบเช้า):** ตรวจสอบการส่ง "รูปเข้างาน" ของพนักงาน
- **Evening Batch (รอบปิดร้าน):** ตรวจสอบเอกสารปิดร้าน 7 รายการ ได้แก่ รูปเข้างาน, รูปออกงาน, สลิปโอน, หน้าสมุดขาย, สลิปฝากตู้, รูปรีวิวลูกค้า และรูปรีวิว Google Map โดยทำงานตามเวลาปิดร้านของแต่ละสาขา (19:00, 20:00, 21:00 น.)
- **ระบบตามงาน 2 รอบ (2-Round Notification):**
  - **รอบที่ 1:** แจ้งสถานะภาพรวมว่าสาขาส่งครบหรือขาดส่งรายการใดบ้าง
  - **รอบที่ 2 (หลังรอบแรก 10 นาที):** หากสาขาใดยังส่งไม่ครบ จะส่งข้อความแจ้งเตือนซ้ำ (หากส่งครบแล้วระบบจะไม่ส่งข้อความกวนใจ)
- **การจัดการวันหยุด:** หากพนักงานระบุว่า "หยุด" หรือ "ลา" ในรอบเช้า ระบบจะรับทราบและข้ามการทวงถามเอกสารในรอบเย็นให้อัตโนมัติ

## 📁 โครงสร้างไฟล์ (File Structure)
- `shop_tracker_cron.py`: สคริปต์หลัก (Python) สำหรับดึงข้อมูลจาก Google Sheets วิเคราะห์เงื่อนไข และส่งแจ้งเตือน Telegram
- `run_tracker.sh`: สคริปต์ Shell สำหรับใช้ผูกกับระบบ Cronjob หรือ macOS LaunchAgent

## ⚙️ การทำงานเบื้องหลัง
ระบบดึงข้อมูลผ่าน `gog` CLI (Google Workspace CLI) เพื่ออ่านข้อมูล Timestamp ล่าสุดของวันที่ปัจจุบันจาก Sheet สาขาทั้ง 9 สาขา และส่งข้อความรายงานเข้ากลุ่มรวม (รวมก้อย กุ้ง) และกลุ่มย่อยของแต่ละสาขา
